# TOEIC Practice Test — 20 Questions

เว็บข้อสอบภาษาอังกฤษแนว TOEIC จำนวน 20 ข้อ แต่ละข้อมี 5 ตัวเลือก

## วิธีเปิด
เปิด `index.html` ด้วยเว็บเบราว์เซอร์ได้ทันที

## วิธีนำขึ้น GitHub Pages
1. สร้าง Repository ใหม่บน GitHub เช่น `toeic-quiz`
2. อัปโหลด `index.html`, `style.css`, `script.js`
3. ไปที่ **Settings → Pages**
4. เลือก **Deploy from a branch**
5. เลือก branch `main` และโฟลเดอร์ `/ (root)`
6. กด Save แล้วรอ GitHub สร้างเว็บไซต์

เว็บมี:
- ข้อสอบ 20 ข้อ
- 5 ตัวเลือก/ข้อ
- ระบบเลือกคำตอบ
- ปุ่มก่อนหน้า/ถัดไป
- แถบความคืบหน้า
- จับเวลา 20 นาที
- ตรวจคะแนนอัตโนมัติ
- เฉลยและคำอธิบายหลังส่ง
- Responsive สำหรับมือถือและคอมพิวเตอร์
